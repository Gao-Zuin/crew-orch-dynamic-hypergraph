# 共享 ORCH 知识的 Flash 验证

仍为 HT-R3 的 SoftTaskGraph + SoftTaskPolicy + Embodied 路径；本次输入修订的 profile 为 `task_hypergraph_reports_v4`，不另建超图实现。

## 改动

- 从原 ORCH knowledge_base.json 直接读取 general 与当前任务条目（去除完全重复项），不再只读入审计快照。所有 worker 的通信/动作请求与组织器的真实 system 请求都收到共享块。
- 给所有角色提供四种职业实际使用的 Embodied 单步动作菜单，避免组织器仅收到 navigate/cut 等能力标签。没有把 ORCH 的“任意距离一个 Move”或 Cut all option 描述误接到单步执行器。
- 保留已核实的精确动作语义，明确直升机可运载携带平民的消防员、到安全点后由消防员放下平民。标明 Scout Fire 专属要求的适用范围、安全距离等是建议而非新增动作门控。
- 感知阶段增加 ORCH 风格的程序坐标辅助，只解析原本传入的局部网格；不增加中心实时环境信息。大于 5 个同类目标使用边界区域并注明区域内并非每格都是该目标。
- 没有添加 ORCH 的 manager、阶段队列、option 执行器、计划评审、强制重组或新完成条件。阶段/option 提示依赖不存在的执行状态，不能作为静态知识照搬。
