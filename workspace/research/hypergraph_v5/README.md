# 精简协作层与 10–15 人实验

## 本次修改

正式运行路径改为 compact_v5：

1. 状态提示只给本组位置、资源、agent 类型、是否在直升机内及观测年龄。完整 session/version/provenance、地图缓存仍保存在 ledger，不重复放入每次 prompt。
2. 删除提示中没有真实任务 contract 支撑的 ACTIVE/空 contract，以及被动组摘要和多份地图坐标。保留当前组标识与状态版本。
3. HA 不再附加向 leader 汇报的指令，作为纯局部状态提示比较。HR 额外提供 leader 和由实际路由规则计算的可联系列表。
4. 同一轮投递失败/抑制仍逐接收者记录，但对 sender 合并成一条反馈，避免广播生成多条相似历史。
5. 普通运行的 local-no-delta 只做观测记录，不再自动发 leader 提醒。局部未变化可能是正常等待或未编码的全局效果。

保留状态失效处理、动作后快照、投递反馈、分组/重叠和原 validator。完整 context、contract/handoff 和 HG guard 保留为独立协议测试接口，不进入本批普通执行路径。空间分组暂不改动，本次集中修改提示体积和重复反馈。

这些调整针对已有的提示冗余与不可解释提醒；没有按容量死锁增加手工运输策略。是否改善任务结果由新批次观察。
