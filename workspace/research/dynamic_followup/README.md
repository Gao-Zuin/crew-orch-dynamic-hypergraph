# 动态超图长期实验入口

每次唤醒先读本文件、`STATE.json`、`JOURNAL.md`，再读 batch 的 `progress.json` 与各运行事件。不要依赖聊天记忆恢复进度。

范围固定为当前轻量 SoftTaskGraph / SoftTaskPolicy / Embodied；完整任务图与旧空间图仅作历史参考。用户授权持续实验、分析失败、最小实现修复和相关测试，不因失败随意增加组织限制、强制拆组或更换 seed。

Cycle编号表示工作日志轮次，不是新的超图架构；当前仍只有上述一条轻量动态图运行路线。实际活动批次以STATE.json及其指向的progress.json为准，下面的Cycle001路径属于历史批次。

每轮：

1. 检查实际进程和已有 status，区分运行中、完整结束、中断和基础设施失败；不重复启动同一 case。
2. 阅读真实世界变化、动作、消息与图变化；图提交不等于重组，指令返回不等于任务完成。
3. 提出一个可证伪的修正假设。优先修输入/状态/接口错误，不把模型策略失败直接硬编码成规则；没有明确错误时记录假设并先补证据。
4. 修改源码与有意义的回归测试；保存修改前失败、修改后测试结果。行为变化另标批次，不回填旧结果。
5. 真实运行使用冻结副本；保留失败、不自动重试。每轮写 JOURNAL，更新 STATE 的证据、结果、待验证事项和下一步。
